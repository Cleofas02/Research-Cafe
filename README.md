
# ☕ Research Cafe

A  web system for a school research cafe, built with React, Tailwind CSS, and Firebase. Focuses on upload and saving files in the database, to be use by future research for their related literature in our school

## 📌 Features

- Uploading and saving studies
- Real-time database updates via Firebase
- Keywords search engine 
- Vercel-ready deployment

## 🛠️ Tech Stack

- React
- Tailwind CSS
- Firebase
- JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/Cleofas02/Research-Cafe.git
cd Research-Cafe
npm install
npm run dev
