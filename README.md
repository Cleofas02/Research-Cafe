# ☕ Research Cafe

A React + Firebase project developed as a final research system for research cafe. Focuses on uploading, saving the literature and acting as online library for future researchers of the school.

## 📌 Features

- Uploading research literature and studies
- Search engine for keywords 
- Firebase real-time database integration
- Vercel deployment-ready setup

## 🛠️ Tech Stack

- React
- Tailwind CSS
- Firebase
- JavaScript
- Vite

## 🚀 Getting Started

```bash
git clone https://github.com/Cleofas02/Research-Cafe.git
cd Research-Cafe
npm install
npm run dev
